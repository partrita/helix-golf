Helix Golf

Function into Class

3개의 함수를 3개의 메서드를 가진 클래스로 변환합니다.

Before

def calculate_area(length, width):
    result = length * width
    return result

def calculate_perimiter(length, width):
    result = 2 * (length + width)
    return result

def calculate_volume(length, width, height):
    result = length * width * height
    return result

After

class Calculator:
    @staticmethod
    def get_area(len, wid):
        return len * wid

    @staticmethod
    def get_perimiter(len, wid):
        return 2 * (len + wid)

    @staticmethod
    def get_volume(len, wid, hei):
        return len * wid * hei

class Calculator:

  1. % 전체 파일 선택

  2. s 현재 선택 영역 내에서 검색하여 하위 선택 영역 생성. calculate 입력 후 <enter>를 눌러 해당 단어의 모든 항목 선택

  3. c 누른 후 get 입력하여 각 "calculate" 단어를 "get"으로 변경

  4. <esc> 일반 모드로 복귀

  5. O 각 커서 위에 빈 줄 생성 후 다음 입력:

    @staticmethod

  6. <esc> 일반 모드로 복귀

  7. jj 각 커서를 아래로 두 줄 이동

  8. vgl 각 커서 이후 줄의 나머지 부분 선택

  9. y 각 선택 영역 복사

  10. x<alt-d> 각 커서의 줄을 선택하고 선택 영역을 복사하지 않고 줄 삭제

  11. xb 각 커서 줄의 마지막 단어 선택

  12. R 각 선택 영역을 이전에 복사한 선택 항목으로 교체

  13. kxx 각 커서를 한 줄 위로 이동하고 해당 줄과 아래 줄 선택

  14. s 정규식으로 하위 선택 영역 생성. length|width|height 입력 후 <enter>를 눌러 length, width, height 단어 선택

  15. b 각 단어의 시작 부분으로 이동

  16. 매개변수에서 처음 3글자만 유지하고 나머지를 버리기 위해 lll로 4번째 문자로 이동

  17. e 각 단어 끝까지 선택 후 d로 삭제

  18. % 전체 파일 선택 후 >로 들여쓰기

  19. O 위에 새 줄 생성하고 삽입 모드 진입, <backspace>로 추가 탭 삭제

  20. 다음 내용 입력:

    class Calculator:
