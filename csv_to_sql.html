  1. % 전체 파일 선택

  2. <alt-s> 줄바꿈을 기준으로 여러 선택 영역으로 분할

  3. "yy 나중에 사용하기 위해 "y" 레지스터에 복사(yank)

  4. s 누르고 패턴 \d 입력 후 <enter>를 눌러 모든 숫자에 선택 영역 생성

  5. d 선택 영역 삭제 (모든 숫자 제거)

  6. hh 각 단어의 끝에 위치하도록 뒤로 2글자 이동

  7. b 각 단어의 시작 부분까지 선택하여 모든 단어를 선택

  8. ms` 각 단어를 백틱으로 감싸기

  9. ` 모든 문자를 소문자로 변환

  10. x 각 줄을 선택한 다음 _로 끝 공백 제거

  11. ms( 각 줄을 괄호로 감싸기

  12. I 각 줄의 맨 앞에서 삽입 모드 진입

  13. 다음 내용 입력:

    INSERT INTO `database

  14. <esc> 일반 모드로 복귀

  15. a 백틱 뒤에서 삽입 모드로 진입한 후 다음 입력:

    .`table

  16. <esc> 일반 모드로 복귀 후 la로 여는 괄호 바로 앞에서 삽입 모드 진입

  17. 공백 추가 후 다시 <esc>로 일반 모드 복귀

  18. A 각 줄 끝에서 삽입 모드로 진입하여 다음 입력:

    VALUES (

  19. <esc> 눌러 삽입 모드 종료 (닫는 괄호 위치에 커서 배치)

  20. "yP "y" 레지스터에 복사해 둔 항목들 붙여넣기

  21. S,<enter> 각 쉼표를 기준으로 현재 선택 영역을 여러 개로 분할

  22. ms' 각 항목을 작은따옴표로 감싸기

  23. A; 각 줄 끝에 세미콜론 추가

  24. <esc> 일반 모드로 복귀 후 Fl로 각 "location"의 소문자 "l"에 커서 위치

  25. ; 각 선택 영역을 단일 폭 선택 영역으로 축소

  26. ~ 각 "l"을 "L"로 대소문자 전환
